# 闸体系细则（检索可达性 / grounding / 应用报告）

> 本文件承载 `SKILL.md` §6.1 的操作细则。**闸的权威定义只在 SKILL.md §6.1 一处**，
> 本文件不重定义闸的存在与否，只展开判据、经验与踩坑。

## 一、闸1 检索可达性（报告项）专项

口径分布在三处，统一在此：

- **检索词来源**：未提供 `--retrieval` 时，`pipeline_assemble.py` 自动从 book_meta 篇名抽 ≥4 字实词片段兜底（`auto_retrieval_terms`：去书名号/括号后按标点切），闸1 不再整体跳过；篇名即 03 正文 `# ` 标题原文，OCR 把篇名某字读错该片段就搜不到——正是 闸1 要暴露的。外部清单仍优先（专名类短核心词召回更准）。
- **检索空间 = 正文 + 03 头部**（`fulltext_clean + "\n" + 03头部` 计数，非仅正文）：书名/作者/丛书名等书目信息（在前辅文为图片页时仅 03 头部含）在交付件内可达即算通过，避免误报缺失。仍建议 retrieval_list 用「书里实际写法」的专名（如本书用虎符非兵符、厢兵非厢军），否则 闸1 暴露的是"清单写法错配"而非流水线缺陷。
- **引文逐字率比对源 = raw ∪ clean，且 clean 先剥留痕再归一**：只对 `fulltext_raw` 比对会误伤两类合法引文（① 笔记引用纠正后正字，raw 里没有 → 假未命中；② 该句被留痕标记切断 → 假未命中）。故比对源取「原始底本 ∪ 已纠错权威底本」，clean 先经 `TRACE_RE`（`〔原书(?:OCR)?作…〕`/`〔跨页合并…〕`/`〔存疑：…〕`）剥除留痕——**正则兼容新旧两式记号**；03 现已无留痕（§3.1），此剥除为防御性保留。
- **全角分节号 `［n］` 会把句子切成两半**：学术译本常把原典章节号／勒布本页码写成**全角** `［4］` 插入句中，而 `norm()` 原只剥半角 `[n]`——跨越分节号的合法引文全部假未命中。现已在 `norm()` 一并剥除 `［\d+］`。**类推**：遇到学术译本／古籍译注本，先看句中有无 `[n]` `［n］` 这类分节标。另两条收尾经验：① 派工模板要写死"说话人归因（xx 说：）不许写进引文行"；② 逐字率未达标的先看是不是这类结构性原因，确认是笔记改写时才动手改笔记。
- **检索清单须用「原书实际写法」，并防时代错置**：清单里写读者习惯词而原书不用，报缺失只会误导排查方向。两型：① 同义异写（`春秋时期`→原书作 `春秋时代`）；② 时代错置（1938 年成书的《中国文化与中国的兵》不可能出现 `第二次世界大战`，书中只作 `欧战`）。**做法**：先 `grep` 原书确认写法再定清单；确认书中确无该概念时直接删词，并在 00/回执里说明删因。
- **长标题 / 带引号标题假阴性（清单构造约定）**：闸1 用**精确子串**匹配。文献选编类书的篇名＝长公文标题且常内嵌引号，OCR 会**断行＋引号拆散**，精确全串必假阴性——正文确在，不是缺漏。**做法**：判重前先用「去引号＋忽略换行」的子串确认正文存在，把"假阴性"与"真缺失"分开；清单里长标题只取**短核心词**（如「两参一改三结合」），或在审计侧做软匹配容错。本质：被 OCR 拆散的长串不适用精确全串匹配，取核心词更稳。

## 二、gen-time grounding（check_patch 第⑧步）+ 跨行连行

- **grounding 基准 = body0（已 systematic 通改的 struct），不是 raw struct、也不是 03。** 每条 active 补丁 `old` 须在 body0 对应页块精确出现≥1 次；0 命中即判「幻觉 / phys 错 / over-specific」拒收。为什么验 body0：assemble 施在 body0，验 raw struct（未通改）会让「old 含 systematic 错字」的 over-specific per-phys 漏判（102 条噪声根因），验 03（已纠错成品）必然找不到 old（113 条无效 systematic 噪声根因）。与闸1b 互补不重叠：闸1b 验 03 高频错形，grounding 验 body0 每条补丁存在性（含闸1b 不查的低频 per-phys）。
- **两项增强**：① B1 多命中 WARN——per-phys 补丁在 body0 命中 >1 处时告警（old 太短/上下文不足，偏页风险，建议 old 带≥6字上下文使全书唯一命中）；② B3 phys/book 页码区分告警——per-phys 0 命中 ERROR 时，自动检测 phys+5..+15 范围内是否有 old 命中，若有则追加「疑似 phys 误用了 book 印页」，帮助区分「phys 填错页」与「old 凭空制造」。
- **grounding 在 assemble 强制链**：pipeline_assemble 加载补丁前调 `validate_corrections.py`（schema 硬闸）+ `check_patch.py`（grounding 第⑧步）；不在链则 113 条无效 systematic 全逃过（P2 实证）。
- **跨行连行**：`find_span`/`iter_spans` 的 level-2「换行容忍」在 needle 字符间容忍任意 `\n/\r`，命中返回**原 body 坐标系**的 (start,end)，替换后不真正改写存储 body 的换行结构（即「仅匹配阶段视图、按坐标回拆」，留痕插入坐标不错位）。基层真实用例「见剌\n史」已验证；`scripts/test_logical_join.py` 固化回归。`check_patch` 第⑧步对 `status=deleted` 的 tombstone 整条跳过校验，仅留防御性 WARN 抓"deleted 仍残留"（真·误删）。
- **组装应用报告两路径统一**：`emit_apply_report` + `_FORM_NEAR_SET` 抽到 `_common.py` 单一真相源。两条路径 03 同用 `<<<PAGE phys=N ...>>>` 锚（EPUB 的 phys＝SEC idx），故 `_page_blocks` **页块定域** + **A+C 修正**（增字型补丁先剔 new 再判 old）对两路径通用；旧 EPUB 版漏这两项，整篇扫 old 易把目录页/重复短语合法同串误报残留。注：`emit_apply_report` 只"报告"残留，不"施加"补丁；某书 03 真残留须回 `corrections/` 补丁或重跑 `apply_corrections_core` 解决。
