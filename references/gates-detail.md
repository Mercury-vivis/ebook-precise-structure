# 闸细则（闸A 抽检 / 闸B 书账互释 / 补丁可落地性）

> 本文件承载 `SKILL.md` §6.1 的操作细则。**闸的权威定义只在 SKILL.md §6.1 一处**，
> 本文件不重定义闸的存在与否，只展开判据、经验与踩坑。

## 一、闸A 可读性抽检

- **抽页**：按 phys 均匀抽，每章至少 1 页，总量 ≥10 页；不足 10 页全抽。抽到的页要记"已读过"，清单为空也记。
- **基准独立于台账**：`ocr_confusion_dict` 不依赖 corrections，账本没列的错字也能抓——这是唯一能打破「账本没列即全闸全盲」的机制。
- **两类条目**：`compound`（复合错形，如 `磨宋→唐宋`）可直接 `count(wrong)>0` 判疑似；`char_class`（裸单字）**禁止裸计数**，必须带 `ctx` 正则上下文（如 `剌(?=史)`），否则误伤合法词（磨勘 / 磨练 / 秋毫）。
- **输出格式**：`phys=112 | 「国民党车队」| 疑为「国民党军队」`。**必须带 phys**——清单指向书里的位置，不指向台账。
- **判定由人**：抽检是抽样不是证明；清单里每条要么改 03 并入 04，要么记为误报放行。

## 二、闸B 书账互释

- **正向**：04 记录的每处改动（含 §四 人工修订），在 03 干净正文（先剥 `〔原书作…〕` 留痕）里 `old` 残留 = 0、`new` 命中 > 0。
- **反向**：03 里出现的非原文改动，在 04 有登记。差异按三类报，不合成一个数：
  ① 已登记（消除误报）——账里有，只是要放宽空白/全半角才复现；
  ② 页归属错位——账的 `phys` 写错，补丁按全局回退落在别的页，报「台账 phys=A / 实测 B」；
  ③ 真未登记——账上谁都解释不了，才是要动手的。
  实现要点：记录源必须是 `corrections/*.json`（`patch_manifest.json` 只落 9 个键，不含
  `regex`/`systematic`，以它为准会把正则通改当字面量，维民实测假报 47 页）；匹配语义必须与
  `apply_corrections` 一致（`iter_spans` + old≥4 全局回退），否则已登记改动会被报成未登记。
- **只查 active**：`status:"deleted"` 的补丁不查。
- **交付指纹只报告**：04 末尾记 00–03 的 sha256，`check_book` 逐件比对；不符 = assemble 定稿后 00–03 有改动。不得做成阻断——修订路径本来就要求「定点改 03 + 04 §四 留痕」，改完指纹必变。
- **失败不自动重算**：报差异清单交人裁决。书对账错 → 04 §四 登记放行；账对书漏 → 补改 03 并回写 04。
- **引文逐字率（C 口径）**：只核笔记「关键原句摘录」小节，四类分栏（✅03逐字 / ⚠️仅raw / ⚠️03疑似残留 / ❌均无），报告项不阻断。比对源 = raw ∪ clean：只比 raw 会把「引用纠正后正字」判成假未命中；归一化剥 `〔…〕` 元数据（留痕 / 校记）、分节号与全部标点空白。全篇引号句口径（`--all-quotes`）实测 68%/74.8%，混入大量标题与自造框架名，不用于交付报告。

## 三、补丁可落地性（事中校验）

- **写一条验一条**：`check_ledger.py --one` 核 `old` 是否在该页真实存在、是否多命中、是否与已有补丁冲突。
- **0 命中只有两种原因**：`old` 写错（含把解释说明误写进 old 字段），或 `phys` 偏页。前者改 `old`，后者归位 `phys`——**都不是"书错了"**。
- **跨页断裂**：`old` 含换行或前后半跨页时，缩短为单页内子串并按实际页归位。
- **多命中**：`old` 太短，带 ≥6 字上下文使全书唯一命中。
- **形态三类**：`old==new` 空转 / `old` 写成一行而底本跨行 / 同页两条 `old` 命中区间相交。
  三者都不影响施加，但会让「照 old 去正文里搜」搜不到、或让 assemble 静默丢一条。
- **不做事后总清算**：事后上千条积压错误是噪声，必然被"想办法让它闭嘴"绕过；事中一条是信号。

## 四、检索可达性（报告项）

- **检索空间 = 正文 + 03 头部**：书名 / 作者 / 丛书名在前辅文为图片页时只存于 03 头部，交付件内可达即算通过。
- **清单用「原书实际写法」**：同义异写（`春秋时期` vs 原书 `春秋时代`）、时代错置（1938 年成书不可能出现 `第二次世界大战`）都会制造永久红字；确认书中确无该概念时直接删词并说明删因。
- **长标题只取短核心词**：篇名被 OCR 断行＋引号拆散时，精确全串必假阴性，正文其实在。

## 五、应用报告与页块定域

- **页块定域**：`_page_blocks` 按 `<<<PAGE phys=N>>>` 切块，补丁只在声明页块内生效——整篇扫 `old` 会把目录页 / 重复短语的合法同串误报残留。
- **A+C 修正**：增字型补丁先剔 `new` 再判 `old`，避免"改对了还报残留"。
- **跨行连行**：`find_span` / `iter_spans` 的「换行容忍」在 needle 字符间容忍任意 `\n` / `\r`，命中返回**原 body 坐标**，替换后不改写存储的换行结构（即「仅匹配视图、按坐标回拆」，留痕插入坐标不错位）。
- **两路径统一**：`emit_apply_report` 与 `_FORM_NEAR_SET` 抽到 `_common.py` 单一真相源，PDF / EPUB 共用；`test_emit_apply_report.py`、`test_logical_join.py` 固化回归。
- `emit_apply_report` 只"报告"残留，不"施加"补丁；03 真残留须回 `corrections/` 补丁或重跑 `apply_corrections_core` 解决。
