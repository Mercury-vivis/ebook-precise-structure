# 闸细则（闸A 抽检 / 闸B 书账互释 / 补丁可落地性）

> 本文件承载 `SKILL.md` §6.1 的操作细则。**闸的权威定义只在 SKILL.md §6.1 一处**，
> 本文件不重定义闸的存在与否，只展开判据、经验与踩坑。

## 一、闸A 可读性抽检

- **抽页**：按 phys 均匀抽，每章至少 1 页，总量 ≥10 页；不足 10 页全抽。抽到的页要记"已读过"，清单为空也记。
- **基准独立于台账**：`ocr_confusion_dict` 不依赖 corrections，账本没列的错字也能抓——这是唯一能打破「账本没列即全闸全盲」的机制。
- **两类条目**：`compound`（复合错形，如 `磨宋→唐宋`）可直接 `count(wrong)>0` 判疑似；`char_class`（裸单字）**禁止裸计数**，必须带 `ctx` 正则上下文（如 `剌(?=史)`），否则误伤合法词（磨勘 / 磨练 / 秋毫）。
- **输出格式**：`phys=112 | 「国民党车队」| 疑为「国民党军队」`。**必须带 phys**——清单指向书里的位置，不指向台账。
- **判定由人**：抽检是抽样不是证明；清单里每条要么改 03 并入 04，要么记为误报放行。

## 二、闸B 书账互释

- **正向**：04 记录的每处改动（含 §四 4.2 人工修订），在 03 干净正文（先剥 `〔原书作…〕` 留痕）里 `old` 残留 = 0、`new` 命中 > 0。**`old == new` 的空转记录不判残留**（v2.3.1）：这类记录不产生任何改动（典型 `type=存疑`「拿不准、只登记不改」），书里留着 old 是天经地义；旧口径把 54 条存疑登记全判正向残留、闸B 假阻断（《中国的历史脉动》实测 55 处阻断里 54 处是此类）。空转记录另由 `check_ledger` ⑤ 形态学报告（不阻断）提示「该不该标 deleted」——那边问账目卫生，这边问「书里还有没有没改完的错」。**§四 4.4「考据裁定与预处理处置登记」不参与正向**（v2.2.0）：该节是人写裁定记录（多为「裁定不修」），「原文→改后」行形是记录在案的决定而非修订动作，参与正向会把合法文本误判残留。**§四 4.1「经核实撤销的补丁」与 4.3「派生件同步」同样不参与**（v2.3.1）：4.1 是 `status=deleted` 墓碑的审计节，撤销补丁的 old 本就该留在 03（或修正已由通改代劳），当修订解析等于把台账已排除的东西重新放进正向，与「只查 active」冲突；其实测危害——《中国的历史脉动》54 条撤销补丁被当修订解析，phys=45 一条因 old/new 含弯引号被 `_REV_RE` 截断成假 old==new（正向残留误阻断），phys=5/28 两条 new 被截成短串（反向复现把引文括注整段删掉，假报 2 页「③ 真未登记」）。4.3 是 notes→01/02 同步记录，不是修订动作。**判定域＝正文区**：`_body_of` 取首个真锚（`<<<PAGE phys=N` / `<<<SEC idx=N`，N 为数字）之后的全部内容；03 头部（书名／来源／类型／页码体系／锚点等说明行）是技能脚手架、由简体模板＋`book_meta` 字段值拼成，不是书的内容，不参与残留判定。繁体书的简→繁 systematic 通改会把头部简体逐条判成"残留"（2026-10-21 实测：575 页繁体书假残留 28 处、正文 0 处；全库 159 本中 7 本共 54 条同类假残留）。无真锚时回退全文——宁可误报，不可 fail-open。边界**不能**用 `text.index('<<<PAGE')`：头部「锚点」说明行本身含 `<<<PAGE phys=N book=M>>>` 字样，会切在头部中间。
- **反向**：03 里出现的非原文改动，在 04 有登记。差异按五类报，不合成一个数：
  ① 已登记（消除误报）——账里有，只是要放宽空白/全半角才复现；
  ② 页归属错位——账的 `phys` 写错，补丁按全局回退落在别的页，报「台账 phys=A / 实测 B」；
  ②附 全书 0 命中——`old` 特异化后（或补丁已删）原串全书 0 命中，不是漏改；
  ③ 真未登记——账上谁都解释不了，才是要动手的；
  ④ 结构标注（2026-10-22）——整页差异**全部**是行首 Markdown 标题标记：判定条件是
  `difflib` 给出 `insert` 且插入串恰为 `#{1,6}`（`la` 为空、`lb` 全匹配 `^#{1,6}$`），
  同一页若还有任何非标题差异则整页仍归 ③（混合页只把标题项并行列示，不额外计页）。
  含义是「03 有标题、struct 侧没有」，属结构标注不属内容改动，**不计入未登记**。
  处置：`01c_add_headings.py` 把标题补进 `fulltext_struct.txt` 后重跑 assemble，本项清零且重跑不丢。
  实测（《文史通义校注》，corrections 为空、struct 中 `#` 行 = 0、03 中 = 166）：旧口径报 15 页 / 165 项
  「未登记」，其中 165/165 全是纯标题标记、其它差异 0；加 ④ 后 ③ 归零、④ 单列 15 页 / 165 处。
  实现要点：记录源必须是 `corrections/*.json`（`patch_manifest.json` 只落 9 个键，不含
  `regex`/`systematic`，以它为准会把正则通改当字面量，维民实测假报 47 页）；匹配语义必须与
  `apply_corrections` 一致（`iter_spans` + old≥4 全局回退），否则已登记改动会被报成未登记。
- **只查 active**：`status:"deleted"` 的补丁不查。
- **交付指纹只报告**：04 末尾记 00–03 的 sha256，`check_book` 逐件比对；不符 = assemble 定稿后 00–03 有改动。不得做成阻断——修订路径本来就要求「定点改 03 + 04 §四 留痕」，改完指纹必变。
- **失败不自动重算**：报差异清单交人裁决。书对账错 → 04 §四 登记放行；账对书漏 → 补改 03 并回写 04。
- **引文逐字率（C 口径）**：只核笔记「关键原句摘录」小节，四类分栏（✅03逐字 / ⚠️仅raw / ⚠️03疑似残留 / ❌均无），报告项不阻断。比对源 = raw ∪ clean：只比 raw 会把「引用纠正后正字」判成假未命中；归一化剥 `〔…〕` 元数据（留痕 / 校记）、分节号与全部标点空白。全篇引号句口径（`--all-quotes`）实测 68%/74.8%，混入大量标题与自造框架名，不用于交付报告。

## 三、补丁可落地性（事中校验）

- **写一条验一条**：`check_ledger.py --one` 核 `old` 是否在该页真实存在、是否多命中、是否与已有补丁冲突。
- **0 命中只有两种原因**：`old` 写错（含把解释说明误写进 old 字段），或 `phys` 偏页。前者改 `old`，后者归位 `phys`——**都不是"书错了"**。
- **跨页断裂**：`old` 含换行或前后半跨页时，缩短为单页内子串并按实际页归位。
- **多命中**：`old` 太短，带 ≥6 字上下文使全书唯一命中。
- **形态三类**：`old==new` 空转 / `old` 写成一行而底本跨行 / 同页两条 `old` 命中区间相交。
  三者都不影响施加，但会让「照 old 去正文里搜」搜不到、或让 assemble 静默丢一条。
- **manifest id 内容键（v2.2.0）**：补丁 id = `源文件名#sha1(old|new|phys)[:10]`（`_common.patch_stable_id` 单一真相源，同文件重复内容加 `#2/#3` 出现序），**不随条目增删 / corrections 文件重生成漂移**。历史方案「文件名#下标」在下标平移时把墓碑误标到另一条 active 补丁上（实测：一本书闸B 8 处残留中 2 处、全库 4 本共 1036 条 manifest 与 corrections 状态相左）；legacy（下标式）墓碑按 `(source, old, phys)` 内容自动迁移，内容暂缺的墓碑转 `orphan_tombstones` 复现自动生效。**改 corrections 后直接重跑 `gen_patch_manifest.py` 即可，无需任何手工 manifest 操作**（历史上的「先删后生」规避已作废）。
- **不做事后总清算**：事后上千条积压错误是噪声，必然被"想办法让它闭嘴"绕过；事中一条是信号。

## 四、检索可达性（报告项）

- **检索空间 = 正文 + 03 头部**：书名 / 作者 / 丛书名在前辅文为图片页时只存于 03 头部，交付件内可达即算通过。
- **清单用「原书实际写法」**：同义异写（`春秋时期` vs 原书 `春秋时代`）、时代错置（1938 年成书不可能出现 `第二次世界大战`）都会制造永久红字；确认书中确无该概念时直接删词并说明删因。
- **长标题只取短核心词**：篇名被 OCR 断行＋引号拆散时，精确全串必假阴性，正文其实在。

## 五、应用报告与页块定域

- **页块定域（施加侧）**：`_page_blocks` 按 `<<<PAGE phys=N>>>` 切块，补丁只在声明页块内生效——整篇替换 `old` 会把目录页 / 重复短语的合法同串误伤。**勿与判定侧混淆**：残留判定（`is_residual_full`）**不**按页块定域，而是扫整个正文区（见本节首条），否则台账 `phys` 写错时真残留会被漏判（N5 教训）。
- **A+C 修正**：增字型补丁先剔 `new` 再判 `old`，避免"改对了还报残留"。
- **跨行连行**：`find_span` / `iter_spans` 的「换行容忍」在 needle 字符间容忍任意 `\n` / `\r`，命中返回**原 body 坐标**，替换后不改写存储的换行结构（即「仅匹配视图、按坐标回拆」，留痕插入坐标不错位）。
- **两路径统一**：`emit_apply_report` 与 `_FORM_NEAR_SET` 抽到 `_common.py` 单一真相源，PDF / EPUB 共用；`test_emit_apply_report.py`、`test_logical_join.py` 固化回归。
- `emit_apply_report` 只"报告"残留，不"施加"补丁；03 真残留须回 `corrections/` 补丁或重跑 `apply_corrections_core` 解决。
