# 书类型 → 输出结构库（10 类 + 兜底）

> 本文件由 SKILL.md §4 迁出（v1.16.0 拆分，内容逐字未改）。SKILL.md 保留类型索引与指针；
> **生成 01_章节详解.md 前按类号到本文件取模板**。两铁律（正文叙述段 / 笔记写法）在本文件开头，务必先读——不守会让 02 速查卡静默漏抽。

> 按"知识结构"分类型，不按学科标签。主控方在受理环节选定主类型；交叉书用"主类型 + 辅类型补字段"；兜底自定义。

**正文叙述段铁律（全类通用）**：每章除下方"卡片字段"（概况/核心概念/关键要点/关键原句摘录等）外，凡连续成段的"叙述主体"必须——① **转述，禁整段搬运**：用自己话概括论点/事实（1–3 句/段），严禁整段或近整段逐字抄原书；② **金句限量**：仅留不可替代的精彩原句，每节（### 节）≤ 1–2 句，用 `>` 引用块 + 锚点，其余转述；③ **锚点全角**：引用锚一律 `（SEC idx=N）`（EPUB）/ `（原书页码 M）`（PDF），**禁半角 `(SEC idx=N)`**；④ **史料罗列砍并**：多例证压缩为"据 X、Y、Z 等指出…（结论）"一句，不逐一铺陈；⑤ **保骨架**：论点→证据→推论链每环留关键 1–2 句。**目标叙述段 ≤ 原篇幅 40%。** 不守此律会造成"前半抄书、后半卡片"的割裂——所有并行 Agent 须共用同一份派工模板（含本铁律），不得各自发挥。

> ⚠️ **笔记写法两铁律（assemble_epub.py 抽取硬约束，不守→02 速查卡静默漏抽）**：
> ① 每个 `## N. 章名` 的 `N` 必须是 `book_meta.json` 的**全局篇序**（1–N，对应 `chapters[].no`），不能用单元内局部 1/2/3；否则该篇被 `split_chapters` 的 `if gno not in no2name: continue` 整篇跳过，02 卡片（概念/名句）全空。
> ② 卡片字段（`**核心概念**`/`**论证要点**`/`**关键原句摘录**` 等）必须是**独立粗体行**（行尾即结束，可带尾冒号 `**核心概念**：`），内容另起行写。**禁止**写成 `- **X**：`（带"- "前缀）或 `**X**：说明文字`（内容跟在冒号后同行）——这两种都让 `SUBSEC_RE = ^\*\*[^*]+\*\*[:：]?\s*$` 匹配失败：卡片漏抽（02 完整性报告项随即全空），且 `- **X**：内容` 会漏进「概念卡」污染。§4 各模板里的 `**核心概念**：关键概念 3–6 个…` 是「字段规格说明」不是「笔记原样」，照抄即错。实战踩坑与对策见 §3E「EPUB 组装路径踩坑」。


① 事件 / 战役型（军事史料、战史）
```
## N. 章节名（时期）
**概况**：时间（起止）、区域、敌我兵力、指挥员、结果。一段话。
**过程要点**：按准备/实施/结局分阶段，4–8 条，每条一句话 +（原书页码）。
**几点认识**：核心观点 3–8 条 + 关键原文引句（逐字 30–80 字）+（原书页码）。
**关键原句摘录**：2–4 段，逐字 + 页码。
```
② 思想 / 理论型（军事思想、政治哲学原典，如《孙子兵法》《战争论》）
```
## N. 章名（本章论题）
**本章论题**：一句话说清本章要回答的问题 / 主张的命题。
**核心概念**：关键概念 3–6 个，每个一句话定义 +（原书页码）。
**论证要点**：前提→推理→结论，4–8 条，每条一句话 +（原书页码）。
**关键原句摘录**：2–4 段最能体现命题的原文，逐字 + 页码。
**篇间逻辑关系**：本章概念如何承上启下（思想类骨架是逻辑链，必填）。
```
③ 人物 / 生平型（传记、人物研究）
```
## N. 章节名（时期/阶段）
**生平概览**：人物基本信息（生卒、籍贯、身份、事功）一段话。
**重要经历**：按时间/阶段 4–8 条，每条一句话 +（原书页码）。
**性格/思想/才能**：核心特征 3–6 条，每条一句话 +（原书页码）。
**关键原句摘录**：2–4 段最能体现人物的原文/评语，逐字 + 页码。
**历史评价**：作者/时人/后世评价（原书页码）。
```
④ 制度 / 沿革型（制度、职官、军事体制演变）
```
## N. 章节名（制度主题）
**制度概说**：该制度的定义、性质、设立背景一段话。
**沿革脉络**：设立→发展→演变→废止，按阶段 4–8 条，每条一句话 +（原书页码）。
**机构/职官/内容**：制度的具体构成 3–6 条，每条一句话 +（原书页码）。
**关键原句摘录**：2–4 段制度条文/描述原文，逐字 + 页码。
**影响与评价**：该制度的历史影响（原书页码）。
```
⑤ 地理 / 空间型（区域、地形、军事地理）
```
## N. 章节名（区域/空间）
**区域概说**：位置、范围、自然条件一段话。
**地形/关隘/要地**：关键地理要素 3–6 条，每条一句话 +（原书页码）。
**军事地理意义**：该区域在军事/历史上的价值 3–6 条 +（原书页码）。
**关键原句摘录**：2–4 段地理描述原文，逐字 + 页码。
**关联事件**：发生于此的战事/事件（原书页码）。
```
⑥ 通史 / 断代型（通史、断代史）
```
## N. 章节名（时期）
**时期概览**：时间范围、总体特征一段话。
**大事脉络**：按时间顺序 6–10 条，每条一句话 +（原书页码）。
**政治/军事/制度要点**：按领域各 2–4 条 +（原书页码）。
**关键原句摘录**：2–4 段代表性原文，逐字 + 页码。
**承上启下**：本章与前后时期的衔接。
```
⑦ 方法论 / 史学型（方法、理论、史学著作）
```
## N. 章节名（方法/理论）
**方法主旨**：一句话说清该方法的要旨/解决的问题。
**核心概念**：3–6 个关键概念，每个一句话定义 +（原书页码）。
**操作/论证要点**：方法步骤或论证链 4–8 条，每条一句话 +（原书页码）。
**关键原句摘录**：2–4 段原文，逐字 + 页码。
**适用范围与局限**：该方法的适用边界（原书页码）。
```
⑧ 编年 / 纪事型（编年史、纪事本末）
```
## N. 章节名（时间段）
**时期概览**：时间范围一段话。
**纪事条目**：按年月排序 6–10 条，每条含时间+事件+（原书页码）。
**关键转折**：该段时期的重大转折点 2–4 条 +（原书页码）。
**关键原句摘录**：2–4 段原文，逐字 + 页码。
```
> 与 ⑩ 的分界：⑧ 是编者连贯叙述的编年 / 纪事叙事（章＝时间段或事件叙事，章内按年月排纪事条目）。若每章＝一篇独立文献（自带作者 / 成文时间，如文件选编、资料汇编、论文集），归 ⑩ 文献选编 / 文集型，不归 ⑧—— 两者卡片字段与 02 形态都不同。历史上有把文献选编书标注为「⑧ 编年 / 纪事型（文献选编）」的存量写法，属借用 ⑧ 之名的临时标注，新书一律按 ⑩ 归。

⑨ 带注古籍型（经注交嵌・集注本，如《十一家注孙子》）
```
## N. 章名（本章论题）
**经文**：本章经文原文（逐字分段，标注段号）。
**注家注文**：按注家归集注文，格式「〔注家〕曹操曰：...（原书页码）」，保留〔夹注〕标记不剥离。
**注家分歧**：同一经文处各注家观点的分歧对比 2–4 条 +（原书页码）。
**校勘要点**：整理者/底本校勘说明（如"某字，竹简本作某"）+（原书页码）。
**关键概念**：3–6 个关键概念，每个一句话定义 +（原书页码）。
**论证要点**：经文本身的论证 4–8 条，每条 +（原书页码）。
**篇间逻辑关系**：本章如何承上启下（必填）。
```
⑩ 文献选编 / 文集型（文件选编、资料汇编、论文集；每章＝一篇独立文献，如《建国以来重要文献选编》）
```
## N. 篇名（作者·时间）
**文献概况**：来源、作者、成文/发表时间、背景与性质，一段话。
**核心内容要点**：3–8 条，每条一句话概括该篇主旨 +（原书页码）。
**关键原句摘录**：2–4 段最能体现该篇立场/结论的原文，逐字 + 页码。
**历史意义与影响**：该篇的历史地位、后续影响或争议（原书页码）。
```
> 02 速查卡形态（type ⑩ 专属）：不走默认的「战争 / 技术 / 事件按年排序」抽取 ——pipeline_assemble 的 extract_events 对「章＝独立文献」的书会抽空 / 抽错。改走「文献目录＋名句」形态：① 全书 N 篇一览（篇名＋作者＋时间＋原书页区间）；② 读法建议；③ 关键要点速查（按篇汇核心要点，带锚）；④ 关键名句速查（按篇汇原句，带锚）。PDF 路径用定制 build_02_docform 类脚本生成；EPUB 路径由 assemble_epub 按 type 切换（⑩ 已登记在 NARRATIVE_TYPE_PREFIX，渲染「要点＋名句」而非「概念＋名句」）。

**兜底：自定义结构** —— 10 类之外，主控方手工写输出结构填入模板。

⑪ 大事记 / 编年史型（按年/月/日编排的大事记、编年录、附录文献体；每章＝一个时间段，如《六十年来中国与日本》第八卷 1920-1931 大事记+附录）
```
## N. 年份/时间段（如 1928 年）
**时段概况**：本年/本时段的核心事件与背景，一段话（原书页码）。
**大事编年**：按时间顺序列出 5–15 条关键事件，每条格式「日期/月份：事件简述（原书页码）」；同日多事件合并。
**关键人物与动向**：本年活跃的关键人物及其行动/立场变化 3–8 条（原书页码）。
**关键文献/条约**：本年签署或发布的重要文件 2–5 条，含名称/日期/核心内容（原书页码）。
**历史意义**：本时段在全书中的承上启下地位与影响（原书页码）。
```
> 02 速查卡形态（type ⑪ 专属）：走「大事年表＋关键人物＋关键文献」三轨：① 全书大事年表（按年汇核心事件，带锚）；② 关键人物索引（人物→出现年份/事件，带锚）；③ 关键文献/条约索引（名称→年份/核心内容，带锚）。附录型章节（条约/文件汇编）走 ⑩ 文献选编形态。大事记体章名常含空格/年份前缀（如「1920 年」），pipeline_assemble 章名匹配须容忍空格与前缀（P2-C2）。

**02 速查卡规范与类型自适应**：02 概念索引/名句索引为全类通用下限（概念≥20/名句≥30，不足则全量）；**事件脉络仅适用于叙事型书（①③④⑤⑥⑧⑩），非叙事型书（②⑦⑨）走 §4 已有双轨（核心概念+关键名句），不强求事件脉络**。该分组与脚本 `NARRATIVE_TYPE_PREFIX`、SKILL.md §4.1 三处必须一致，改一处须同步三处。
