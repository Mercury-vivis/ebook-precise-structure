# 非正文内容识别与标记（批注 / 注释 / 引用）

> 本文件是 `SKILL.md` §3F 的全文展开，执行「批注类书籍」精读时必读。
> **触发条件**：古籍汇校、脂评本、带批注的电子书（批注夹批/侧批/眉批插入正文），
> 或用户要求区分批注与正文。
> 经验来源：《红楼梦脂评汇校本》精读（8,768 个图字占位符中 8,725 个为脂批版本/位置标记，3,892 个批注 span）。

## 3F.1 易用性筛选原则（只做真正影响正文的）

判断标准：**是否行内插入正文、是否打断阅读流、是否影响引用准确性**。三者同时满足才做特殊标记。

| 类型 | 是否行内插入 | 是否标记 | 理由 |
|------|------------|---------|------|
| **夹批/侧批/眉批** | 是 | **必须** `〖批〗` | 直接插入正文，严重打断阅读 |
| 回前批/回后批 | 否（独立段落） | 不做 | 楷体+独立段落已自然区分 |
| 脚注/尾注 | 上标号行内，内容文后 | 可选（低优先） | 上标①②③已自然区分，内容在独立段落 |
| 引用/引文 | 否 | 不做 | 引号/缩进已区分 |
| 题诗/题词 | 否 | 不做 | 居中/缩进独立段落 |
| 凡例/整理说明 | 否 | 不做 | 独立章节，有明确标题 |
| 插图/图注 | 否 | 不做 | 图片占位符已区分 |
| 校改记号(某)[某] | 是 | 不做 | 原书的一部分，保留原样 |

**结论**：默认仅标记**行内批注**（夹批/侧批/眉批）。其余类型不做特殊标识，避免过度标记影响阅读。

## 3F.2 标记体系

统一使用 `〖〗` 罕用符号包裹（与原书字符零冲突，可一键批量转斜体/高亮/颜色）：

- `〖批〗...〖/批〗` —— **批注**：版心外小字（侧批/页码角）、版心 y 界外小字（眉批/书眉）、有色小字
- `〖注〗...〖/注〗` —— **注文/译文**：版心内通栏小字（随文注文、今译、注释、独立成行的夹批）

**为什么不用 Markdown 斜体 `*...*`**：原书回目标题可能含 `*` 字符（如 `荣国府收养*林黛玉`），与 Markdown 斜体语法冲突，导致渲染器配对错乱、整段正文变斜体。

**批量转换**：`〖批〗`/`〖注〗` 前后标记→`*` 即变斜体；→`==` 即变高亮；→`<span style="color:red">` 即变红字。

## 3F.3 EPUB 侧识别方法（三层递进）

**第一层·CSS 类识别**（最可靠）：扫描 stylesheet.css，按类名语义判断——`small*`=小字批注、`annotation`/`comment`=批注、`marginal`=旁注、`interlinear`=夹注。排除 `footnote`/`endnote`/`quote`/`caption`。

**第二层·HTML 标签识别**：`<sup>`=脚注号、`<blockquote>`=引用、`<img>`=图片。

**第三层·语义+位置特征**（CSS 无法区分时）：
- 回前批：回目标题后、正文首段前的楷体段落
- 回后批：正文末段后、下一回前的楷体段落
- 批注语义：以版本+位置标记开头的行内文本（如 `〔甲侧〕`、`〔庚眉〕`）

**CSS 属性兜底**：类名不匹配时，检查 `font-size`（小于正文）+（`color` 非黑 或 `font-family` 含楷体）。

## 3F.4 PDF 侧识别方法

PDF 无 CSS 类，需依赖格式属性或坐标。各路径的格式信息获取点不同，**关键在格式信息必须在"文本块产出端"就保留**：

| 路径 | 脚本 | 格式信息获取点 | 识别能力 |
|------|------|--------------|---------|
| 路径一（有文字层 PDF） | `01a_raw.py --with-format` | 提取时用 `get_text("dict")` 保留字体/大小/颜色/坐标 → `fulltext_raw.jsonl` | 高——小字+红色=批注，缩进=引用 |
| 路径一·重 OCR 变体（文字层劣化） | `01a_ocr.py`（重 OCR，**不属路径三**） | 重 OCR 时可保留 bbox 坐标 → `fulltext_raw.jsonl` | 中——坐标+字号推断 |
| **路径三（PaddleOCR 三件套接入）** | `00_ingest_bookocr.py` 消费 `book_ocr.py` 预产出 | **格式信息在 外部工具机 `book_ocr.py` 预产出端保留**：产出 `<名>_blocks.jsonl`（**行级**：每条 OCR 行一条，含 bbox/size/color/score）→ 接入时 `--format-jsonl` 转成 `fulltext_raw.jsonl` | 中——全书正文锚定 + 版心四界；六书实测见下 |
| 简单文字层 | `01a_raw.py`（默认，不带格式） | 仅纯文本 | 低——只能靠语义识别 |

**识别机制**：`preprocess_nonbody.py` PDF 模式按**全书正文锚定**分层——全书通栏行（宽≥页宽×40%）字号聚类，从大到小取第一个合格簇（行数≥2 或字数占比≥5%）的中位为正文锚，小字=字号<锚×0.8；版心四界（通栏行 P2/P98 横界、P5/P95 纵界）外小字→〖批〗，版心内小字→〖注〗。单页锚定在注占多数的页原理性失效（正文段末短行被通栏过滤剔出、字号分布连续），故全书定锚。

> **实现注意（2026-10-16 踩坑）**：① ε-邻接字号聚类有**链式合并陷阱**——相邻差归簇会让 35→34→32→30→29→28 逐步滑成一片、正文簇与注文簇连体（间隔 0.08 时孙子锚落到 28），聚类间隔须按数据实测收紧（现 0.05）；② **合格簇**条件（行数≥2 或字数占比≥5%）防两类劫持——孤立装饰大字/短标签（单行短字跳过）、回目篇名大字；③ 版心界用全书**通栏行分位数**估计，勿用固定页宽/页高比例——段末短行贴版心内缘会被页宽比例误判页边，书眉页码会超出固定页顶线（老子实测 y1=173>8%）。

**六书实测形态光谱**（2026-10-16）：

| 书 | 版式 | 效果 |
|---|---|---|
| 孙子兵法译注（郭化若） | 原文/【注释】【译文】【试笺】同页三区 | 注/译/笺 59 行全标〖注〗、页眉页码 9 行标〖批〗，正文零误标 |
| 孙膑兵法（中华书局） | 今译/正文/注释三字号+左竖排书脊栏 | 注/译 39 行标〖注〗，2 行边缘误判 |
| 金圣叹批评本水浒 | 双行小字夹批**嵌正文行间** | 纯夹批行标出；嵌行夹批=物理边界（见下） |
| 十一家注孙子 | 通栏随文注文（占半书），字号差 1.25×且行高连续 | **部分命中**（重叠带 28-31 行漏）；全书锚防住锚定落注文层的零识别 |
| 老子今注今译 | 正文+【注释】块 | 注文行+书眉页码全标 |
| 脂砚斋庚辰校本 | 学术整理本：校记/转写脂批与正文**同字号** | 仅水印与边缘行标出——同字号无信号，物理边界 |

**物理边界（不自动识别，属 Stage 3 精读按文本特征处理）**：
1. **同视觉行大小字混排（嵌行夹批）**：OCR 检测层已把夹批小字与正文大字融进同一检测行（金圣叹本实测），任何下游粒度都无法恢复字号信号；
2. **同字号整理本**（校记/转写批注行内，如脂校本）：无字号差异信号。EPUB 路径不受影响（CSS/语义三层法）。

> **路径定义澄清**：路径三**不是**技能侧对 PDF 重扫描。路径三是**外部工具机 `book_ocr.py`（PPStructureV3 + GPU）预产出三件套 → `00_ingest_bookocr.py` 接入 → 跳过 Stage 1+2 → 进入 Stage 3** 的流程（定义见 SKILL.md §0.3）。`01a_ocr.py` 是路径一在文字层缺失/劣化时的重 OCR 变体，不跳过 Stage 1+2。识别批注所需的格式信息，在路径三里**必须由 `book_ocr.py` 在预产出三件套时就保留**（产出 `<名>_blocks.jsonl`），接入端才能消费。

**路径选择**：有文字层的数字 PDF，增强路径一（`--with-format`）即可拿到格式信息，比 OCR 更准确更快；只有纯扫描件（无文字层）才走 `01a_ocr.py` 重 OCR 或路径三（三件套接入）。不是"高标准就走路径三"。

**路径一增强**：`01a_raw.py --with-format` 用 PyMuPDF `get_text("dict")` 替代默认 `get_text()`，输出 `fulltext_raw.jsonl`，每行一个文本块，含 `text`/`font`/`size`/`color`/`bbox`/`phys`。

**路径三增强**：`book_ocr.py` 预产出三件套时，额外输出 `<名>_blocks.jsonl`（**行级粒度**：块内按页级 OCR 行几何归属拆开，每行一条 `text`/`bbox`/`size`(行高)/`score`/`color` 记录；块级回退保底）；接入时 `00_ingest_bookocr.py --format-jsonl` 消费它，转成与路径一同构的 `fulltext_raw.jsonl`，供 `preprocess_nonbody.py` 识别批注。

## 3F.5 脚本入口：`preprocess_nonbody.py`

```bash
# EPUB 模式：扫描解包目录，输出修改后 HTML（供重新提取）
python scripts/preprocess_nonbody.py --epub-dir <解包目录> --out-dir <标记后HTML目录>

# EPUB 模式：直接输出带标记纯文本
python scripts/preprocess_nonbody.py --epub-dir <解包目录> --text-out <输出.txt>

# PDF 格式模式：读取带格式 JSONL，输出带标记文本
python scripts/preprocess_nonbody.py --format-jsonl <fulltext_raw.jsonl> --text-out <输出.txt>

# 自定义批注 CSS 类（覆盖默认关键词匹配）
python scripts/preprocess_nonbody.py --epub-dir <解包目录> --annotation-classes small1,small2,small3
```

**PDF 模式的格式来源（两条，都产出同构 `fulltext_raw.jsonl`）**：
- **路径一**：`01a_raw.py <pdf> <work> --with-format` → 直接产出 `fulltext_raw.jsonl`
- **路径三**：`book_ocr.py` 预产出三件套时额外产出 `<名>_blocks.jsonl`，接入时 `00_ingest_bookocr.py --bookocr-dir <三件套目录> --work <work> --format-jsonl` → 转成 `fulltext_raw.jsonl`

**流程位置**：Stage 1（提取）之后、Stage 2（结构清洗）之前。EPUB 模式输出修改后 HTML，需重新跑 `01b_extract_epub.py` 提取；PDF 模式直接输出带标记文本，可作为 `fulltext_struct.txt` 的输入（或供 Stage 3 参考）。

**默认批注 CSS 类关键词**：`small`、`annotation`、`comment`、`marginal`、`interlinear`、`zhupi`、`note`（排除 `footnote`/`endnote`/`quote`/`caption`）。

- [ ] 正文未被误标记（grep 抽查 `〖批〗` 前后上下文）
- [ ] 03 中标记保留，未被 `strip_correction_traces` 误删
- [ ] 00 总览中说明标记含义
